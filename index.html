How to Use

  • Copy your folder structure
    Use the tree command in terminal or copy from your file explorer or copy from AI-generated structure
  • Remove all comments & extra text
    Only keep the tree lines with folder/file names
  • Paste into the text area
    Make sure the first line is the root folder name
  • Click "Generate ZIP File"
    Download your folder structure as a ZIP file

Features

Creates ZIP files with 90% accuracy
Most files and folders are correctly generated but occasional path errors may occur
Generates empty files with proper extensions
File types are preserved even when paths might be slightly off
Works with common tree characters (├ ─ │ └)
Parses standard tree format but complex nesting can sometimes cause issues
Fast processing with mostly correct structure
Quick conversion but may place some files in slightly wrong locations
